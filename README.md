# Accessible Palette

A lightweight, accessible color palette tool for designers and developers.

## Features (planned)

- 🎨 Interactive palette editor
- ✅ WCAG AA/AAA contrast checker
- 👁️ Color-blindness simulation
- 🔧 Auto-suggest accessible alternatives
- 📤 Export as CSS variables, JSON, or Tailwind config

## Tech Stack

- Vanilla JavaScript + Vite
- chroma.js for color math
- Plain CSS with custom properties

## Getting Started

\`\`\`bash
npm install
npm run dev
\`\`\`
